# Go Learning

## 目录介绍

```text
go-learning/                           # 项目根目录
├── apps/                              # 开发的独立小应用
├── algo/                              # 算法学习
├── examples/                          # 框架学习，demo等，独立go mod
├── internal/                          # 工具包，基础包，给apps，algo等包
├── go-release/                        # go release版本新的语言特性使用样例，
│    ├── go1.18
│    └── go1.25
│
├── projects/                          # 学习和展示项目结构、架构或设计的样例
├── standard-library                   # go标准库使用样例
│
├── docs/                              # 文档
│   └── README.md
│
├── go.mod
├── go.sum
├── Makefile                           # 构建命令
└── README.md                          # 项目说明
```
